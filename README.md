# 🌼 ngu-studio

> *"A digital space dedicated to preserving cherished memories, lessons, and expressions of gratitude for Teacher Ngu."*

### 📖 About The Project

`ngu-studio` သည် ဆရာမ ငု သင်ကြားပြသပေးခဲ့သော သင်ခန်းစာများ၊ အမှတ်တရများနှင့် ကျေးဇူးတင်လွှာများကို Front-End Web Technology များ အသုံးပြု၍ လှပစွာ သိမ်းဆည်းဖန်တီးထားသည့် Web Project တစ်ခုဖြစ်ပါသည်။

- **Dedicated To:** Teacher Ngu
- **Tech Stack:** HTML5, CSS, JavaScript
- **Purpose:** Personal Memory Archive & Web Showcase
